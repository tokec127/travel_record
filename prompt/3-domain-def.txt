# 사용자 요구사항


# 필요성

- 여행가서 현지 정보를 내가 원하는만큼 활용할 수 있는 앱이 없다.
- 내가 원하는 정보는 다음과 같다.
	- 내가 찍은 사진과 동영상
	- 검색한 현지 명소, 식당, 아이템, 뉴스, 날씨 등
	- 내가 작성한 메모나 글
	- 내가 그날 이동하고 둘러본 장소
- 위에서 언급한 정보는 각기 다른 앱을 통해 데이터를 생성하지만, 이 정보를 모아서 사용자에게 원하는 형태로 제공하는 앱이 없다.


# 기본 구성

## frontend

- 사용자 인증창
- 권한 허용 처리
- google map과 연동하여 날짜별 이동경로 표시
- 이동경로 선택
	- 상단에 주요 활동 기록(결제,메모,날씨 등) 표시
	- google map에 상세 이동경로 표시 + 정보 아이콘 표시
	- 정보 아이콘: 사진,동영상,메모,결제 등의 수집자료를 데이터 종류별 아이콘
- 해당 아이콘 클릭시 상세 정보 표시 (사진이면 사진 표시 등). 상세정보는 팝업창으로 표시

## backend

- 앱 시작하면 이동경로 확보
- 사진, 동영상 경로 및 시각, 장소, 추가메모 등의 정보수집
- 결제 관련 메시지 수신시 현지 시각 결제 정보 및 구매내용을 메모화
- 사용자가 검색한 자료(시각,장소 포함)의 요약 메모 정리



# 디버깅 기능

- 각 기능 수행에 대한 처리결과 로그에 남김
- 로그를 확인할 수 있는 기능 필요
- 로그는 디버그 모드일때만 활성
