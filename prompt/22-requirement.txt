# 여행기록

- 여행카드 목록을 그림 ~/temp/1.png처럼 디자인해줘
- 여행카드마다 (순번) (대표그림) (상단에 제목과 시각), (하단에 메모)를 표시
- 그림에서 순번색은 날짜마다 다른색으로 표시
- 그림에 (S), (E)는 그날 시작과 종료를 알림
  - (대표그림)에는 (S), (E) 해당 시기(예, 오전,오후)의 그림을 아이콘으로 표시
  - 여행카드 (S)와 (E) 참고
- 결제항목의 (대표그림)은 영수증 이미지로 표시 (여행카드 1번)
- 동영상 (대표그림)은 해당영상 첫화면에 동영상 표시 (여행카드 5번)
- 메모는 (대표그림)에 메모관련 아이콘으로 표시 (여행카드 6번)
- 사진의 (대표그림)은 동일 그룹의 첫번재 사진 (여행카드 3번)
  - 동일 그룹의 판단 기준
    1. 사진을 시간순서로 정렬
    2. 현재 사진과 이전사진과의 장소가 100m 이내 & 시간이 30분 이내
    3. 동일 그룹의 첫번째 사진과 마지막 사진의 장소는 100m를 벗어날 수 있고, 30분을 초과할수 있음
- 모든 여행카드 메타데이터(날씨, 메모, 시각, 사진상세정보, 결제정보등)는 앱의 로컬 저장폴더에 저장하여 관리


# 2.수정사항

- 여행카드 안쪽 위아래 여백을 0으로 수정
- 여행카드 중 시작 위치, 종료 위치 카드를 다음과 같이 수정
  - 하단 메모 부분 사용자 입력 메모로 대체. 없으면 공백으로 표시
  - (대표그림)에 "S", "E" 표시 대신 그림 ~/temp/1.png 처럼 순번 위치에 숫자대신 "S"와 "E"로 표시.
- 동일 그룹으로 판단되는 사진을 8장 찍었음에도 여행카드는 첫 사진만 보임
  - 동일 그룹으로 판단되는 사진 수를 (대표그림)에 추가로 표시 (예, ~/temp/1.png의 3번 카드)


# 3.수정사항

- "여행 기록 .. 편집" 줄에서 편집 대신 추가 아이콘 "+" 표시
- 추가 터치하면 팝업창에 아래처럼 추가 내용 입력
    - 종류: 결제, 메모 선택
    - 제목:
    - 메모: 
- 사용자 입력에 따라 작성시각에 맞는 순번 여행카드를 생성하고
- 해당 여행카드에 대표그림, 제목, 시각, 메모를 표시
- 동일그룹으로 묶인 여행카드를 선택하면 팝업창 이미지에 동일그룹에 속한 사진을 3개씩 grid형태로 표시. 3x3을 벗어나면 이미지 표시 크기는 고정하고, 사진 배열을 drag하도록 수정

# 4.수정사항

- 여행카드의 가로선보다 대표사진이 제일 위에 표시해
- 제목 1줄, 메모 1줄로 표시 (현재 메모가 2줄 공간을 할당하고 있음. 1줄 공간만 할당해야 함)
- 동일 그룹 여행카드 선택시 팝업창 뜨지 않

# 5.수정사항

- (오류) 여전히 동일그룹 여행카드 선택시 팝업창이 표시돼지 않음
- (수정) 그림 또는 동영상 여행카드 선택시
  - 디자인 시안을 그림 ~/temp/3.png를 참고해서 설계해
  - 사진(또는 동영상) 1개일때: 그림 ~/temp/3.png의 "(1) 사진이나 동영상이 1개일때" 처럼 표시
  - 사진이 9개 이하일때: 그림 ~/temp/3.png의 (2)처럼 표시
  - 사진이 9개 초과할때: 그림 ~/temp/3.png의 (3)처럼 표시
