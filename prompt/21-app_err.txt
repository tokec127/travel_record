
# 1 기능오류

* "새 여행 만들기"
	- "여행 구분"과 도시 선택하면 나의 여행 항목 표시할때 "도시/나라"로 표시.
  - 국외 도시 선택시 해당 국가명 검색하여 표시할때 영어로 "City/Country" 표시
  - 일정 결정할때 시작일, 종료일 선택 대신 "일정 선택"하여 달력을 표시하고 첫 선택일을 시작일, 두번째 선택일을 종료일로 표시. 
  - 달력에 시작일과 종료일까지의 일정을 다른색으로 표시"

* 나의 여행 -> 선택여행 -> 여행기록 표시
  - 시간순으로 데이터 항목을 상->하로 표시
  - 나열하는 데이터 항목은 다음과 같다.
    - 시작위치 (앱에서 당일 앱 최초 frontend로 실행한 위치) + 시각
    - 사진/동영상
    - 메모
    - 결제
    - 종료 (앱에서 당일 마지막 frontend를 실행한 위치 또는 마지막 위치정보) + 당일날씨, 시각
  - 데이터 항목은 "대표 아이콘(또는 사진) + 부가정보"
    - 사진/동영상의 경우 "사진/동영상" + 시각정보 + 사용자가 입력한 사진 메모 정보
    - 결제의 경우 영수증 아이콘 + 가게(또는 장소), 금액, 종류, 사용자 추가 메모
    - 메모의 경우 메모 아이콘 + 시각정보 + 사용자가 입력한 메모
    - 시작/종료 아이콘 + 시각/장소 정보


# 2 기능오류

* 나의 여행 -> 선택여행 -> 여행기록 표시
	- 사진이나 동영상의 경우 아이콘 대신 썸네일로 표시
  - 종료 위치 표시는 해당일이 지난 후에 표시 (당일은 종료되지 않았기에 표시안됨)
  - 날씨 정보가 포함안됨
  - 항목 표시에서 아이콘 또는 사진을 큰 썸네일 또는 이미지를 사용하고 옆에 부가정보를 표시하도록 수정 (2컬럼으로 표시)
  - 상단 "..." 클릭하면 수정/삭제 표시 및 항목들이 선택 여부를 묻고, 선택된 항목에 대해 삭제 또는 수정하는 기능 추가


# 3 기능수정

* 나의 여행 -> 선택여행 -> 여행기록 표시
  - 항목 선택시 해당 항목을 팝업 표시하여 사용자 메모 수정/추가, 또는 해당 항목 삭제 기능 제공
  - 메모 내용이 수정/추가 되거나 해당 항목이 삭제된 후 여행기록 표시에 변경내용 즉시 적용
