# Android 앱 개발 스킬

## 기본 원칙

- 공통 기능은 Flutter와 Dart로 먼저 구현한다.
- Flutter 플러그인이나 기본 API로 해결할 수 없는 경우에만 Kotlin과 Android API를 사용한다.
- 실제 기능에 필요한 최소 권한만 요청하고, 거부·철회·제한 상태를 처리한다.
- 위치, 미디어, 메시지, 인증 정보와 같은 개인정보를 로그에 남기지 않는다.
- 기존 Android 설정과 Flutter 호출 흐름을 먼저 확인한 뒤 변경한다.

## 주요 검토 항목

- `AndroidManifest.xml`의 권한과 서비스 선언
- 위치 수집 주기, 백그라운드 실행 제한, 배터리 사용량
- Android 앱 생명주기와 프로세스 종료 후 복구
- Android 뒤로 가기와 시스템 권한 화면
- 사진·동영상 저장소 접근 범위
- Kotlin 플랫폼 채널이 필요한지 여부
- 지원 Android SDK와 실제 기기·에뮬레이터 검증

## 구현 기준

- 플랫폼 채널은 필요한 메서드만 정의하고 데이터 형식을 명시한다.
- 백그라운드 작업은 중복 실행과 재시작을 고려한다.
- 권한 요청과 실제 기능 실행을 분리한다.
- 변경 후 `flutter analyze`와 관련 최소 테스트를 실행한다.
