# iOS 앱 개발 스킬

## 기본 원칙

- 공통 기능은 Flutter와 Dart로 먼저 구현한다.
- Flutter 플러그인이나 기본 API로 해결할 수 없는 경우에만 Swift와 iOS 시스템 프레임워크를 사용한다.
- 실제 기능에 필요한 최소 권한만 요청하고, 거부·철회·제한 상태를 처리한다.
- 위치, 미디어, 메시지, 인증 정보와 같은 개인정보를 로그에 남기지 않는다.
- 기존 iOS 설정과 Flutter 호출 흐름을 먼저 확인한 뒤 변경한다.

## 주요 검토 항목

- `Info.plist`의 권한 설명과 기능별 접근 범위
- 위치 수집 주기, 백그라운드 모드, 배터리 사용량
- iOS 앱 생명주기와 백그라운드 실행 제한
- 사진·동영상 접근 권한과 제한된 사진 선택
- Face ID·Touch ID와 Keychain 사용 여부
- 공유 시트와 시스템 권한 화면
- Swift 플랫폼 채널이 필요한지 여부
- 실제 기기와 Xcode 환경에서의 검증

## 구현 기준

- 플랫폼 채널은 필요한 메서드만 정의하고 데이터 형식을 명시한다.
- 백그라운드 작업이 항상 실행된다고 가정하지 않으며 중단·재개를 처리한다.
- `Info.plist`와 capability 설정을 기능에 필요한 범위로 제한한다.
- App Store 심사와 개인정보 안내가 필요한 기능은 구현 전에 확인한다.
- 변경 후 `flutter analyze`와 관련 최소 테스트를 실행한다.
