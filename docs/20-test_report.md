## 오류 리포트

### 1. 여행기록 항목카드 팝업 내용이 잠깐 보여지다 사라짐

| 현상 | 항목카드를 터치하면 팝업창 내용이 잠깐 표시된 후 사라짐. |
|---|---|
| 진단 | 사진 상세 팝업의 `FutureBuilder`가 위젯 빌드마다 새 썸네일 로딩 Future를 생성하고 있었다. 로딩 완료 후 재빌드되면 다시 로딩 상태로 돌아갈 수 있었다. |
| 조치 | 사진 썸네일 Future를 다이얼로그 상태에서 한 번만 생성하고, 팝업 중복 호출과 바깥 터치 해제를 차단했다. |
| 검증 | `dart analyze lib/main.dart`, `flutter test test/widget_test.dart` 통과 |

### 2. 여행기록 항목카드 팝업 내용이 여전히 표시되지 않음

| 현상 | 1번 조치 후에도 항목카드를 터치하면 팝업 내용이 표시되지 않음. |
|---|---|
| 진단 | 시작 위치 팝업은 정상 표시되지만 사진 팝업만 비어 있었다. 사진 미리보기의 비동기 FutureBuilder가 완료 전후로 제약 없는 레이아웃을 만들면서 팝업 내부 크기 계산을 깨뜨리는 문제였다. |
| 조치 | 사진 미리보기 전체를 폭 100%·높이 360px의 고정 컨테이너로 감싸고, 내부 이미지는 `BoxFit.contain`으로 표시하도록 수정했다. `AlertDialog(scrollable: true)`와 루트 Navigator 표시도 유지했다. |
| 검증 | `dart analyze lib/main.dart` 통과, `flutter test test/widget_test.dart` 통과, 실제 Android 기기에서 사진 팝업의 제목·썸네일·촬영시각·장소·메모·버튼 표시 확인 |

### 3. 팝업 UI 변경 후에도 휴대폰에서 변경 전 화면이 표시됨

| 현상 | 소스 수정 후에도 휴대폰의 항목카드 팝업이 이전 UI로 표시됨. |
|---|---|
| 진단 | 소스에는 정사각형 사진·무제목·무라벨·`메모하세요` UI가 반영되어 있었지만, 해당 변경 후 APK를 다시 빌드·설치하지 않아 휴대폰에서 이전 APK가 실행되고 있었다. |
| 조치 | 최신 소스로 debug APK를 재빌드하고 `adb install -r`로 연결된 Android 기기에 재설치했다. 기존 로컬 여행 데이터는 유지했다. |
| 검증 | APK 빌드 성공 및 기기 설치 성공. |

### 4. 시작·종료 카드 대표그림이 실제 날씨와 다름

| 현상 | 9/25 여행일에 흐리거나 비가 왔지만 시작·종료 카드 대표그림이 실제 날씨를 반영하지 않음. |
|--|--|
| 진단 | 시작 카드는 맑음 아이콘, 종료 카드는 밤 아이콘으로 고정되어 있었고, 과거 여행일의 날짜별 날씨를 조회·저장하지 않아 카드에 전달할 날씨 자료도 없었다. |
| 조치 | `WeatherRecord`에 오전·오후 날씨를 저장하고, 과거 날짜는 Open-Meteo 과거 자료에서 상태·최저·최고 기온을 조회해 로컬 저장하도록 수정했다. 시작·종료 시각에 맞는 날씨 상태로 대표그림 아이콘을 선택하도록 연결했다. |
| 검증 | `dart analyze` 관련 소스 통과, `flutter test test/widget_test.dart` 전체 통과. |

### 5. 그룹 여행카드 선택 시 팝업이 표시되지 않음

| 현상 | 동일 그룹으로 묶인 여행카드를 선택해도 `~/temp/3.png`의 (2)·(3)처럼 사진 grid가 포함된 상세 팝업이 표시되지 않음. 제목·메모 영역도 메모가 두 줄 공간을 차지함. |
|---|---|
| 진단 | 그룹 사진 grid가 `AlertDialog`의 바깥 스크롤과 중첩되고, 10장 이상 고정 viewport 안에서도 `shrinkWrap`을 사용해 스크롤 제약이 중복될 수 있었다. 카드의 탭 처리도 자식 위젯의 hit-test 결과에 영향을 받을 수 있었다. |
| 조치 | 1장은 단일 이미지, 2~9장은 `shrinkWrap` 정적 3열 grid, 10장 이상은 `shrinkWrap` 없이 높이 300px 고정·내부 스크롤 3열 grid로 분리했다. 여행카드 전체는 `HitTestBehavior.opaque` 단일 제스처 영역으로 통합했다. |
| 검증 | `flutter analyze lib/main.dart`는 기존 정보 2건만 보고했고, `flutter test test/widget_test.dart`는 전체 통과했다. 전체 `flutter analyze`는 기존 `third_party/kakao_maps_flutter/example` 누락 의존성 오류로 통과하지 못한다. |

### 6. 대표그림 아이콘 위로 여행카드 가로선이 표시됨

| 현상 | 시작·종료·결제·메모 아이콘 대표그림을 가로선이 가로지름. |
|---|---|
| 진단 | 아이콘 대표그림의 배경색이 반투명했고, 아이콘용 Stack이 전체 대표그림 영역을 채우지 않아 뒤의 구분선이 노출됐다. |
| 조치 | 아이콘 대표그림 Stack을 `StackFit.expand`로 고정하고 불투명한 배경색을 적용해 구분선이 대표그림 뒤에만 배치되도록 수정했다. |
| 검증 | 관련 Dart 분석 및 `flutter test test/widget_test.dart` 통과. |

### 10. 여행카드 삭제 후 순번이 갱신되지 않음

| 현상 | 여행카드 삭제 후 동일그룹의 잔여 사진이 카드로 남거나 순번이 이전 상태처럼 보임. |
|---|---|
| 진단 | 동일그룹 카드의 대표 사진만 삭제하고 그룹에 포함된 나머지 사진은 남길 수 있었다. 또한 시작·종료 위치 카드를 내부 숫자 순번에 포함해 첫 일반 여행카드가 2번부터 시작할 수 있었다. |
| 조치 | 카드 삭제 시 그룹 전체 사진을 숨김·삭제하고, 시작·종료 위치와 날씨를 숫자 순번에서 제외한 뒤 남은 일반 여행카드의 순번을 시간순으로 다시 계산하도록 수정했다. 지도 마커와 지도 번호 선택도 같은 기준으로 통일했다. |
| 검증 | `flutter test test/widget_test.dart` 통과. `flutter analyze lib/main.dart`는 기존 정보 2건만 보고했다. |

### 7. 다중 사진 그룹 팝업에서 배경막만 표시됨

| 현상 | 순번 2번의 3장 동일그룹 여행카드를 선택하면 팝업 배경막만 표시되고 본문이 나타나지 않음. |
|---|---|
| 진단 | 단일 사진 팝업은 정상이나 다중 사진 전용 `GridView` 경로에서 `AlertDialog` 배경막만 남고 본문이 표시되지 않았다. 높이 고정만으로는 해결되지 않아 중첩 스크롤 grid가 원인 경로로 확인됐다. |
