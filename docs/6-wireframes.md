## 1. 문서 목적

`docs/1~5`의 개발 규칙, 도메인, PRD, 사용자 시나리오를 바탕으로 실제 UI 설계 전 화면 구조와 이동 흐름을 정의한다.

기준 화면은 스마트폰 세로 화면이며, 화면 폭이 달라져도 콘텐츠가 잘리지 않도록 반응형 규칙을 적용한다.

현재 구현 화면은 인증·여행 목록·여행 상세의 로컬 기능을 기준으로 한다. 여행 상세 지도는 Android 카카오지도이며, 네이티브 날짜별 GPS 폴리라인과 기록 순번 마커를 사용한다. 독립 메모 작성, 공유, 디버그 로그, 해외 Google Map은 화면 시안만 정의된 후속 범위다.

## 2. 참고 범위와 확인 필요 사항

- 인증·여행 생성·자료 수집·메모·경로 조회·과거여행·공유·설정·로그 화면은 기존 문서에 정의되어 있다.
- `할 일 목록`은 기존 도메인과 PRD에 정의되어 있지 않다. 본 문서의 3번 화면은 여행 준비 기능의 제안 와이어프레임이며, 구현 전에 제품 범위를 확정해야 한다.
- 이 실행 환경에서는 `ALT-v` 화면 캡처 기능을 사용할 수 없어 참고 화면 캡처를 첨부하지 않았다.

## 3. 공통 화면 규칙

### 3.1 스마트폰 기준

- 기준 크기: `390 × 844` 논리 픽셀
- 좌우 여백: `16px`
- 상단 안전 영역과 하단 제스처 영역을 침범하지 않는다.
- 세로 스크롤을 기본으로 사용하고, 가로 스크롤은 사용하지 않는다.
- 최소 터치 영역은 `44 × 44px`로 유지한다.

### 3.2 반응형 규칙

| 화면 폭 | 처리 |
|---|---|
| 320~389px | 단일 열, 긴 제목은 최대 2줄, 보조 설명은 줄바꿈 |
| 390~599px | 기준 레이아웃, 카드와 목록을 단일 열로 표시 |
| 600px 이상 | 콘텐츠 최대 폭을 제한하고 지도와 상세 패널을 나란히 배치할 수 있음 |
| 가로 방향 | 주요 화면은 세로를 우선하며, 지도 화면만 가로 확장을 허용 |

### 3.3 상태 표현

모든 주요 화면은 로딩, 빈 상태, 오류, 권한 거부 상태를 정의한다. 성공 결과는 화면 안에서 즉시 확인할 수 있게 한다.

## 4. 스타일 가이드 초안

### 4.1 색상

| 용도 | 값 | 사용 |
|---|---|---|
| 기본 배경 | `#F7F8FA` | 화면 전체 배경 |
| 표면 | `#FFFFFF` | 카드, 바텀시트, 팝업 |
| 기본 글자 | `#17202A` | 제목과 본문 |
| 보조 글자 | `#667085` | 설명과 시간 |
| 주요 색상 | `#2563EB` | 주요 버튼, 선택 상태, 경로 강조 |
| 보조 색상 | `#14B8A6` | 저장 완료, 위치 관련 상태 |
| 경고 색상 | `#D97706` | 권한 확인, 처리 지연 |
| 오류 색상 | `#DC2626` | 실패, 삭제 경고 |
| 구분선 | `#E5E7EB` | 목록과 입력 영역 구분 |

색상만으로 자료 종류를 구분하지 않고 아이콘과 텍스트를 함께 표시한다.

### 4.2 글꼴과 크기

| 요소 | 크기 | 굵기 |
|---|---:|---:|
| 화면 제목 | 24px | 700 |
| 섹션 제목 | 18px | 700 |
| 본문 | 16px | 400 |
| 보조 설명 | 14px | 400 |
| 버튼 | 16px | 600 |
| 캡션 | 12px | 400 |

플랫폼 기본 글꼴을 우선 사용하고, 사용자가 시스템 글꼴 크기를 키워도 내용이 잘리지 않게 한다.

### 4.3 공통 컴포넌트

- 상단 앱 바: 뒤로 가기, 화면 제목, 선택적 보조 액션
- 기본 버튼: 주요 색상 채움, 최소 높이 `48px`
- 보조 버튼: 테두리 또는 텍스트 버튼
- 목록 행: 아이콘, 제목, 보조 정보, 선택적 상태 표시
- 바텀시트: 선택·수정·삭제·공유 같은 화면 하단 작업
- 팝업: 자료 상세, 권한 설명, 삭제 확인

## 5. 화면 목록과 이동

```text
인증·잠금 해제
  └─ 여행 생성·선택
      ├─ 할 일 목록(제안)
      ├─ 날짜별 경로 조회
      ├─ 과거여행 목록
      │   └─ 과거여행 상세·공유
      ├─ 메모 작성·수정
      ├─ 앱 전체 설정
      └─ 디버그 로그
```

## 6. 화면별 와이어프레임

### 6.1 인증·잠금 해제

```text
┌──────────────────────────────┐
│                              │
│          여행기록             │
│   여행 자료를 한곳에 기록하세요 │
│                              │
│       [ 지문 / 얼굴 인식 ]     │
│       [ 기기 PIN 사용 ]        │
│       [ 비밀번호 입력 ]        │
│                              │
│  원격 인증이 필요하면          │
│  [Google] [Apple] [이메일 링크] │
└──────────────────────────────┘
```

- 로컬 인증 성공 후 로컬 자료에 접근한다.
- 최초 로그인 또는 원격 기능 사용 시 원격 인증을 요청한다.
- 인증 실패와 취소 상태를 같은 화면에서 안내한다.

### 6.2 여행 생성·선택

```text
┌──────────────────────────────┐
│ 여행 선택                 ＋ │
├──────────────────────────────┤
│ 진행 중인 여행                │
│ [🇰🇷 서울 여행]              │
│ 2026.09.20 ~ 2026.09.23      │
│                              │
│ 과거여행                     │
│ [🇯🇵 일본 여행]              │
│ 2026.04.10 ~ 2026.04.16      │
│                              │
│             [새 여행 만들기]  │
└──────────────────────────────┘
```

- 국내는 도시, 해외는 나라를 선택한다.
- 시작일과 종료일을 입력한다.
- 여행 목록에서 선택·수정·삭제·공유를 수행한다.

### 6.3 할 일 목록(제안 화면)

이 화면은 여행 준비를 위한 제안 기능이다. 기능을 확정할 때 도메인 모델과 PRD를 함께 갱신한다.

```text
┌──────────────────────────────┐
│ ←  할 일 목록             ＋ │
├──────────────────────────────┤
│ 서울 여행                     │
│ 2026.09.20 ~ 2026.09.23       │
├──────────────────────────────┤
│ □ 여권 확인                  │
│   여행 준비             ⋯    │
│                              │
│ □ 숙소 예약 확인              │
│   여행 준비             ⋯    │
│                              │
│ ☑ 환전                       │
│   완료                  ⋯    │
│                              │
│                              │
│        [완료 항목 숨기기]     │
└──────────────────────────────┘
```

- 추가, 완료 전환, 수정, 삭제를 제공한다.
- 긴 목록은 세로로 스크롤한다.
- 완료 상태는 체크 표시와 텍스트로 함께 구분한다.
- SVG 시안은 [3-todo-list-wireframe.svg](3-todo-list-wireframe.svg)에서 확인한다.

### 6.4 날짜별 경로 조회

```text
┌──────────────────────────────┐
│ ←  2026.09.21              ⋯ │
├──────────────────────────────┤
│ [현지 지도]                  │
│    ●──────●                  │
│     ╲  📷  ●                 │
│      ●── 📝                  │
│                              │
├──────────────────────────────┤
│ 주요 활동                    │
│ [결제 2] [메모 3] [날씨 22°] │
├──────────────────────────────┤
│ 09:30  📷 카페 사진          │
│ 12:10  💳 점심 결제          │
│ 15:40  📝 박물관 메모        │
└──────────────────────────────┘
```

- 국내는 카카오지도, 국외는 Google Map을 현지 지도로 사용한다.
- 지도 아이콘을 선택하면 자료 상세 팝업을 연다.
- 지도 영역은 작은 화면에서도 네이티브 지도 제스처를 우선 처리하며, 상세 정보는 지도 아래에 배치한다.
- 지도는 부모 화면의 스크롤과 제스처가 충돌하지 않도록 지도 영역에서 핀치 확대·축소와 한 손가락 드래그를 우선 처리한다.
- 내 위치 아이콘을 누르면 현재 위치 중심의 도시 규모로 재조정한다.
- 여행 상세 화면은 여행기간·지역 요약, 사진 칩, 지도, 여행 기록 목록 순서로 배치한다.

카드 터치 시 상세 편집 팝업을 연다.

헤더의 `...`를 누르면 선택 모드로 전환되며 시작·종료 카드를 제외한 모든 여행카드에 선택 표시를 보여준다. `삭제·추가` 기능을 같은 영역에 표시하고, 수정 아이콘과 여행기록 목록 제목 옆의 별도 `+` 버튼은 표시하지 않는다.

카드 제목은 장소가 입력된 경우 `제목 @장소`로 표시하며 `@장소`만 순번 원형과 같은 날짜 색상을 사용한다. 장소가 NULL 또는 빈 값이면 제목만 표시한다.

```text
┌──────────────────────────────┐
│ 촬영시각  2026.09.25 14:20   │
├──────────────────────────────┤
│          [큰 썸네일]          │
│ 제목      [제목 입력]         │
│ 장소      [장소 입력]         │
│          [메모 입력]          │
├──────────────────────────────┤
│       [삭제] [취소] [저장]    │
└──────────────────────────────┘
```

시작·종료·사진·동영상·결제·메모 카드는 날짜·제목·장소·메모 구조를 공유하며, 사진·동영상은 제목 앞에 미리보기를 표시한다.

동일그룹 사진 카드의 팝업은 대표 사진 대신 그룹 사진 전체를 메모 입력란과 같은 좌우 폭의 3열 썸네일로 표시한다. 팝업에는 3열·3행 크기의 정사각형 뷰포트를 고정하고, 10장 이상인 사진은 내부를 세로 드래그해 조회한다.

헤더 `...` 메뉴의 `추가`를 누르면 현재 일자·시각을 `YYYY.MM.DD HH:mm` 형식으로 첫 행에 표시하는 추가 팝업을 연다. `종류`는 `메모·결제·사진` 중 선택하고 기본값은 `메모`로 한다. 종류 선택과 `제목·장소·메모` 입력 영역은 밝은 파란색 배경을 사용하며, 사진 선택 시 여행기간 갤러리에서 여러 장을 선택해 여행카드로 저장한다.

```text
┌──────────────────────────────┐
│ 생성시각  2026.09.26 14:32   │
├──────────────────────────────┤
│ 종류      [메모 ▼]           │
│ 제목      [제목 입력]         │
│ 장소      [장소 입력]         │
│          [메모 입력]          │
├──────────────────────────────┤
│          [취소] [저장]        │
└──────────────────────────────┘
```

### 6.4.1 여행 사진 grid

```text
┌──────────────────────────────┐
│ ← 여행 사진          저장 삭제 │
├──────────────────────────────┤
│ [사진] [사진✓] [사진]         │
│ [사진] [사진]  [사진✓]        │
├──────────────────────────────┤
│ 선택 사진 메타데이터          │
│ 현지시각 · 장소 · 원본 경로   │
└──────────────────────────────┘
```

- 여행기간 사진만 표시한다.
- 삭제는 메타데이터와 앱 표시 대상만 대상으로 하며 원본 사진은 유지한다.

### 6.5 과거여행 목록·상세

```text
┌──────────────────────────────┐
│ ←  과거여행                  │
├──────────────────────────────┤
│ 2026.04.10~04.16             │
│ 일본                         │
│                       [선택] │
├──────────────────────────────┤

│  1일차 ━━━  2일차 ━━━        │
```

- 날짜별 동선은 서로 다른 색으로 표시한다.
- 특정 동선을 선택하면 날짜별 경로 조회로 이동한다.
- 공유 전 전체 데이터와 개인정보 포함 여부를 확인한다.

- 키보드가 열리면 입력 영역이 가려지지 않도록 화면을 스크롤한다.

## 7. UI 적용 절차

1. 이 문서의 화면 구조와 누락 기능을 검토한다.
2. 제품 범위가 확정된 화면만 Flutter 위젯으로 분해한다.
3. 색상·글꼴·간격·터치 영역을 스타일 상수로 정의한다.
4. 공통 앱 바, 버튼, 목록 행, 바텀시트, 팝업을 구현한다.
5. 화면 폭 320px, 390px, 600px 이상에서 레이아웃을 확인한다.
6. 로딩·빈 상태·오류·권한 거부·저장 완료 상태를 추가한다.
7. Android와 iOS 실기기에서 인증, 키보드, 권한, 뒤로 가기, 공유 흐름을 검증한다.

## 8. 화면별 검증 기준

| 화면 | 최소 검증 |
|---|---|
| 인증 | 로컬 인증 성공·실패·취소, 원격 인증 실패 |
| 여행 생성 | 국내 도시·해외 나라, 시작·종료일, 잘못된 날짜 |
| 할 일 목록 | 제안 기능 확정 여부, 추가·완료·수정·삭제 |
| 경로 조회 | 빈 경로, 낮은 위치 정확도, 아이콘 팝업 |
| 과거여행 | 목록, 날짜별 색상, 수정·삭제·공유 |
| 메모 | 제목 기본값, 첨부, 키보드, 저장·수정 |
| 설정 | 수집 간격, 배터리 표시, 연동 정보 보호 |
| 공유 | 수신 동의, 연결 끊김, 데이터 범위 확인 |
| 로그 | 디버그 모드 제한, 민감 정보 비노출 |
